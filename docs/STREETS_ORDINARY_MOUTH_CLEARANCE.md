# Complete ordinary junction source widths

An individually solved circular corner can be valid while another incoming
complete profile cuts part of an acute branch's original width. Moving the
branch's radius does not address that profile-plane truncation. Ordinary
complete-mouth clearance runs after established compound/prepared ownership
succeeds. It audits only the remaining standalone ordinary sites, before their
layout, surface, road trims and port resources are published. An invalid local
footprint already covered by a qualified source pool is not re-audited alone.

`ordinary_mouth_clearance.prepare` audits complete original incoming prefixes
with the unchanged 2mm source-strip proof. A valid layout returns by identity.
After a typed containment failure, it first tries the existing certified
analytical sampler on the same curves at the unchanged nominal tolerance.
The derived parameters are retained in the footprint, and the normal analytical
sampler's output must independently pass the same width proof. This can remove
a chord cutting across a lead/arc contact without changing that contact, radius
or source profile. Only a remaining failure accompanied by a continuous crossing
of a complete mouth and another actual incident owned prefix can start a mouth
search. Unrelated containment, curvature and allocation failures remain fatal.

Returning Sections keep their two disjoint endpoint prefixes in the certificate.
Their middle remains road-owned unless an actual complete consumed claim exists.
All prefix batches share the unchanged 8,192-cell allowance.

The search reuses `finite_profile_search.advance` and complete canonical source
station grids. It changes only the failed mouth's finite source station and its
source-aligned boundary leads. Original End identities, Path/Profile objects,
circular contact objects and radii stay fixed. Scope/selection status cannot be
relabelled as a free end. Search retains the complete original owner map,
including actual external aliases and consumed bounds of prepared neighbors.
Derived non-incidence aliases never overwrite those original bounds.

When canonical sampling still fails and no complete mouth crosses another
owned prefix, `ordinary_source_width_fit` may try the already permitted smaller
STYLE radii on one incident corner at a time. The original R10/R1 attempt remains
first; explicit STRICT overrides never enter this branch. Every original mouth
plane, approach, Path and Profile stays fixed, as do all other corner objects.
Each candidate must pass both certified initial sampling and normal canonical
sampling with the same complete-prefix 2mm proof. The accepted radius and exact
attempt sequence are recorded as `STYLE_COMPLETE_SOURCE_WIDTH`; this branch
explicitly reports that the original corner/radius changed. An unrelated
certificate, geometry or allocation error is not caught. At most 64 additional
candidate solves are allowed.

Ordinary-only conflicts enter existing deferred closure with every existing
membership seeded and protected. An actual finite scope spur can use its
existing certified composer. Other prepared/source-owner families raise
`PreparedOwnerClearanceRequired`, carrying their complete original members;
they are never reconstructed as an ordinary footprint or silently ignored.

Every rebuilt footprint must be simple and retain all complete incoming widths
before it can enter normal ownership. A corrected singleton is represented by
one physical-layout group with the same original site and no new SharedClaim.
Normal layout/surface/road/port consumers therefore see the accepted mouth
stations. Source-width, height, drainage and entrance-join checks are mandatory
on its surface. Successful existing groups retain identity and metadata.

Work stays bounded: at most 16 passes, 4096 total candidate stations, 20000 canonical
source samples and 20000 boundary segments per candidate, plus the existing
source-cell and intersection budgets. Canonical grids include complete future
source intervals; rendering-only owned grids cannot support the search.

`ORDINARY_MOUTH_POLICY` participates in the PLAN task version. Exact effective
mouth/certificate records also enter projected layout/surface signatures, which
otherwise omit the global PLAN digest. No old derived product receives a new
signature without normal coordinator reevaluation. Coupled source-owner and
complete-future-source sampling epochs remain independent and preserved.

If all of these ordinary families fail complete source width, late finalization
may use `ordinary_singleton_sources` to union the existing source-backed corner
patches and the site's actual owned prefixes. This remains one original junction
with no consumed claim; it creates no graph cycle or lateral owner. Every
original End, Path and Profile must match exactly, and explicit STRICT radii
must survive unchanged. Native mouth stations remain exact except for the
separately certified dimensional lead reserve described below. Both the original source union and its
normal canonical sampling receive fresh disjoint-prefix proofs. The full source
footprints are retained as area operands. Their physical layout is never sampled
as a fabricated replacement polygon. Resource and unrelated failures propagate.

The authoritative mouth stations belong to the original Sections. Reversing a
Route can round-trip its redundant outward distance by an ULP while leaving all
native trim stations exact. The old exact-distance path stays first. A different
outward representation is accepted only with the same original objects and
orientation, exact native trims, and byte-exact center/tangent/lateral frames.
The two finite-difference frames and denominator used by the offset jet must
also match, preserving the complete affine cross-section and Jacobian for every
lateral coordinate. Physical gradients are checked too. No epsilon or actual
mouth movement is permitted by this representation check; aliases are recorded explicitly.

A separate rule covers a finite root-anchored width transition whose wider
contact already reaches the old complete profile plane. Its normal source union
can need one existing profile-lead reserve beyond that contact to expose the
whole incoming profile. The accepted plane is exactly
`mouth_station(wide_contact + min(0.25 m, 0.05 * width))`. Only a real typed
`DimensionalCorner` area operand can supply that contact; a metadata label, a
narrow endpoint, a borrowed record or an unrelated root-support curve cannot
enable the rule. The inspected corner must belong to that exact area operand.
The contact must have the exact old native source cuts and complete physical
frame. The new plane uses the same original Approach, Route, Path, Profile,
orientation, width and offset, stays strictly inside its finite Route and retains
the same native cut keys. A snap to a free endpoint does not enter this branch.
Every unchanged mouth remains exact. Existing source-union neighbour checks,
complete-profile exposure, remaining-strip exclusion and fresh pre/post-canonical
2 mm source proofs stay mandatory. The rule performs no new radius search.

This reserve is real geometry movement and is never reported as a floating-point
alias. `dimensional_lead_reserve_advances` records its old/new source stations,
normal reserve, original contact and unchanged curvature limit;
`original_mouth_planes_preserved` is false for that correction. Other source
singletons and the bounded three-arm root-support policy still preserve their
original mouth planes. The dependency policy epoch invalidates affected outputs.

An actual exposed zero-height root can also use the existing finite support
curve after the facing STYLE circles exhaust. Only this typed failed singleton
context admits a three-arm donor. Its two maximum donor contacts are the actual
original mouth stations minus the existing profile-lead reserves. The old curve
is tried first; if it exceeds those limits, at most two existing anchored searches
may run. Both bounds, every other circle, the requested curvature limit, complete
root-cap closure and whole-curve exposure remain mandatory. No mouth advancement
is admitted by this policy. Calls without the optional bounds keep their original
geometry and reports unchanged.

## Existing incomplete-profile lead search

A computed original mouth can lie inside another original source operand.
The source-union builder already moves only that incomplete mouth outward by
`max(0.25 m, settings.spacing)`, retaining the same source curves, radii and
transverse profile. It stops only when the whole profile and the remaining
source strip are clear, or the existing finite search/neighbor limits refuse.

[`incomplete_profile_leads.py`](../way/street_network/python_backend/incomplete_profile_leads.py)
now records each such existing step as an `IncompleteProfileLead`. Ordinary
singleton admission requires a genuine typed chain beginning at its exact old
cut and ending at the exact candidate cut. It reruns the old physical union to
prove the old profile was incomplete, checks immutable source-operand hashes,
actual Path/Profile identities, monotone native cuts with unchanged original
incidences, the existing step formula and strictly finite support. Dictionaries,
missing or stale witnesses, changed final cuts and complete old profiles do not
authorize movement. A separate root-support donor's fixed bounds remain intact.

This is reported as actual profile-plane movement in
`incomplete_profile_lead_advances`; it is not a station alias. Normal complete
profile exposure, STRICT radii, prepared neighbors, remaining-strip clearance,
canonical sampling and both fresh complete-width proofs still apply. The
dependency policy epoch invalidates the earlier admission policy.

The three maintained
[`test_python_street_incomplete_profile_leads.py`](../tests/test_python_street_incomplete_profile_leads.py)
checks pass. On the genuine fresh Bergamo Source351 failure, this admits the
existing 0.699999988 m step on original Section364 because its old full profile
is clipped. Local source-union and width checks pass. The subsequent ordinary
mesh-grading gate remains independent; a local source-union pass does not
qualify that Product or the complete city.

## Preserve feasible original dimensional contact planes

The original singleton may already provide feasible contacts for a root-anchored
width continuation. A coarse reach sequence can step past those contacts and
request an unnecessary new mouth plane. Before that existing search, a typed
`OriginalSingletonRootBounds` now supplies one exact candidate: each original
mouth station minus its normal profile-lead reserve.

`compound_dimensional_corners.prepare(..., fixed_stations=True)` certifies only
that pair. It retains the original Paths, Profiles and radius and the same
whole-curve Bernstein curvature certificate. It cannot advance either contact;
a failed fixed candidate declines to the original bounded search. The final
complete-profile exposure, source-width, neighbor and exact-mouth admission
checks are unchanged. Ordinary callers without this opt-in retain their old
search and reports.

For the short original width-change regression, the old narrow mouth is
4.692148672141053 m. Its existing feasible contact is 4.517148672141053 m,
followed by the normal 0.175 m lead. The coarse search had selected 4.55 m and
therefore requested a different 4.725 m mouth. The fixed candidate instead
passes with the original 2 m radius and a certified curvature bound of
0.488458367649392 per metre, keeping that original plane exactly. The normal
backend regression passes, along with thirteen focused dimensional/ordinary
source tests. This geometry correction does not waive subsequent source-height
or publication checks.
