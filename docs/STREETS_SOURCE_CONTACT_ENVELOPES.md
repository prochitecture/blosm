# Finite source-contact envelopes

This preparation fallback handles a narrow, wholly owned original Section
whose two junctions need curb contacts on wider neighbouring source roads.
It runs after the existing circular roots, permitted STYLE radii, dimensional
curbs and root-support families fail. Successful existing preparations keep
their previous path.

The admission starts with a typed finite narrow-lead exhaustion. Both physical
ends of that same original Section must belong to the current compound. An
actual exposed original root cross-section identifies the missing sector.
Original cyclic incidence order identifies the opposite curb walk; proximity
does not create a source connection. Every crossed Section is wholly consumed.
STRICT requests are preserved; a new contact fit uses only the existing STYLE
radius sequence belonging to its original sector.

Each contact retains its actual Approach, Path, width and profile. A contact
on an original outer half-profile is allowed only when its actual facing curb
has zero profile height, its original rise and datum match, and the opposite
member of that complete original Bundle has an active half-profile in the
same compound. The half-profile is never replaced with a full crown. Its
original nonzero transverse derivative remains authoritative.

endpoint acceleration, and a quintic using actual analytical offset-curvature

endpoint acceleration to parameter-speed squared times geometric curvature.

does not reverse. Both constructions use the unchanged positive-projection
and interval Bernstein curvature certificate. The existing zero-jet outward
bell keeps each candidate within one quarter of its smaller contact width.

The patch closes only through explicit original centreline walks. No uniform
