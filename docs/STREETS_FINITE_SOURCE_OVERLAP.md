# Finite source overlap and connected expansion

`overlap_certificate` proves complete proximity of one ordinary Smooth source
route to another finite original corridor. Certified source chords contribute
their curve errors; distance is one-Lipschitz, so endpoint distances plus half
each first chord length bound its entire interval. The physical combined
half-width and permitted fillet diameter remain unchanged.

The default construction preserves the previous sampling. An explicit refined
request tries at most three resolutions, with at most 4,096 samples per source.
The returned certificate records its distance bound, allowance, source curve
errors, sample counts and attempt budget. Failure to prove overlap leaves the
construction unresolved; isolated sample coincidence never establishes it.

After an allowed STYLE fillet fails, `cycle_overlap_expansion` may request the
next real physical junction only when exactly one original incidence is wholly
internal and the other remains external. Both original internal incidences,
the complete consumed interval and exact original external traversal are
required. Scope/selection endpoints, unknown terminals, strict radii and
absorbed or separately reserved approaches do not qualify. The proof uses the
existing minimum STYLE radius. It does not splice across a width change.

The planner then includes that actual connected neighbor and repeats source
ownership, full-width containment, hole, curve and complete-profile checks.
This is a planning certificate; it adds no pavement polygon and grants no
exception to final publication guards. Accepted source-cycle layouts retain
the expansion certificate for review.

If a physical curb contact lies after an owned width change, the two tangent
contacts keep their actual original source Approaches and widths. A bounded
source-incidence walk supplies an internal closure along explicit original
centerlines and finite prefixes. The patch never creates a uniform-width Route
across the change. Actual contact aliases move the corresponding complete
incoming profile past the contact, or request its next real connected owner.
Circle sectors, the original STYLE sequence and STRICT rejection remain intact.

Uncovered original root cross-sections also trigger a bounded, recorded retry.
Same-width circles force the complete facing-root audit before trying the
existing alternate contact side. A near-through width mismatch can instead
use the certified finite dimensional primitive, anchored at the wider original
root with the same accepted radius. An already covered internal sector is
unchanged. Final sampled boundaries of these constructions require complete
width proofs for every consumed Section and explicit original-station prefix,
with the same 2 mm maximum error allocation and explicit hole exclusion.
