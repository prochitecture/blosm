# Complete profiles at finite width-continuation recipients

## The distinction

An ordinary junction's sampled exterior can clip a wider original source strip.
The existing finite source-union fallback then constructs a certified width
continuation from that wider root to the narrower original approach. Its
recipient contact can lie beyond the old ordinary mouth plane.

This is a real change of the generated intersection extent. It is not a station
representation alias. The native Path, source incidence, width and complete
cross-section function stay unchanged, while the full incoming profile is
placed farther along the same finite original approach.

`ordinary_singleton_sources._dimensional_recipient_lead()` admits only that
already generated construction. It introduces no new curve, search, radius
choice or numerical allowance.

## Required evidence

The original and candidate must be the same `Approach` object and therefore the
same native Path, Profile, Section and directed End. The singleton has one
original owner and no consumed claims. Both stations are finite and the native
cut inventory moves monotonically outward without acquiring another Section.
Root-envelope and root-support donor constructions are explicitly excluded.

The actual area inventory must contain a typed `DimensionalCorner` whose own
source layout retains the same Corner. Its physical source boundary must own
the prepared curve object. Its actual certified continuation core must use the
same original arms and radius, with finite measured curvature no greater than
`1 / radius`; report text alone does not establish that certificate.

The recipient must be the narrower of these actual arms. For its prepared
contact c, width w and normal reserve r,

```text
r = min(0.25 m, 0.05 w)
candidate = IntersectionProvider.mouth_station(approach, c + r, settings)
```

The candidate must equal this existing normal station exactly. No arbitrary
extra distance is admitted.

The previous complete-profile port is rebuilt at its original station using
the current port's validated original `CurbCoordinates` station ledger. Every
other original source area operand remains unchanged. The normal polygon union
must show that the previous profile is genuinely incomplete, while the current
profile is complete. The same existing completeness threshold applies; neither
a proximity test nor a fabricated advance record can replace this proof.

The ordinary singleton builder then retains its existing exact mouth inventory,
STRICT-radius inventory, native Path identity, analytical sampling and fresh
continuous 2 mm owned-width checks. Prepared-neighbor and final normal Task
checks remain mandatory. A later Product also runs its original body, entrance,
slope, drainage and float32 publication gates.

## Metadata and caching

The admission is recorded under
`ordinary_complete_mouth_clearance.dimensional_recipient_lead_advances` with
policy `EXISTING_FINITE_WIDTH_CONTINUATION_RECIPIENT_LEAD`. It includes old and
new route stations, actual native cuts, the real advance, prepared contact,
normal reserve, original radius/curvature certificate and both exposure
measures. `original_mouth_planes_preserved` is false when this real advance
occurs. No alias record conceals it.

The ordinary-mouth policy epoch is
`11-proven-finite-dimensional-recipient-planes`. Actual Path/Profile and native
range dependencies continue to belong to the normal Task graph.

## Tests and actual case

`tests/test_python_street_dimensional_recipient_leads.py` reconstructs a small
native three-arm network from maintained source. Positive STYLE cases include
source reversal and rigid rotation/translation. A negative STRICT-circle case
retains the pre-existing refusal to replace that circle with a width
continuation; this admission does not broaden strict curve authority. Other negative
cases cover changed native profiles, a different arm, an unrecorded extra
reserve, missing actual area support, root-donor overrides and fabricated
curvature reports. No artifact pickle or checkpoint is required for these
regressions.

The fresh Bergamo 1,255-Section PLAN reached this case after the earlier
original-circle exit repair. Original site 1097 had a complete-width failure on
the wider Section 548, while the necessary extent change belonged to narrower
Section 549/end 1. The existing radius-2 m continuation had recipient contact
3.3125 m and certified curvature 0.4968040342 per metre. Its normal reserve
placed the complete profile at 3.5625 m. At the old 2.7565031348 m plane, only
0.4999998229 of the full profile was exposed; the new plane had exposure 1.
The real extent change was 0.8059968652 m.

An immutable-runtime admission experiment passed the normal group and Product
constructors with 1,897 pavement quads. It supplied no group, chart, mesh, cuts
or conditions. An independent audit found all 15 hard original-body targets and
51 complete profile samples exact, physical query error below `1.4e-17`, physical
and stored-float slopes below 0.07948 against the unchanged 0.1 limit, joins below
0.004954 and zero isolated minima. Physical/stored edge ratios were below 7.121
and corner sines above 0.2927. The combined 37 focused recipient, auxiliary,
original-source, handoff and field tests passed with unchanged imported source
hashes. This isolated evidence does not replace a fresh whole PLAN,
genuine SurfaceTask or native whole-city import qualification. Development
reports are under `C:/dev/workspace/artifacts/streets/beijing_bergamo_fixes_20261114`.
