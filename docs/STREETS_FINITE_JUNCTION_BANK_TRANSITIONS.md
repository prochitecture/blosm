# Finite source-bank height transitions inside junctions

`CompoundProduct.build(..., source_heights=True)` enables explicit original
source-height conditions. Runtime provider Tasks enable this policy in dev85;
their projected source-height policy token invalidates prior surfaces. This
integration is not a claim that all original city inputs are qualified. The
builder first creates the ordinary boundary data and measures the
real incoming profile gradients. Its configured maximum slope and slope margin
then determine the physical limit supplied to the source-condition policy.
Publication, drainage, profile, join, width and mesh limits are unchanged.

A mixed generated curb chain may need more height-transition length than its
own rounded geometry provides. The failed-only finite-bank policy can use an
adjacent genuine inner half-profile bank that is already inside the same
original junction's influence. Complete incoming profile planes, every actual
zero-height outer bank and the contact-free source body remain hard. No curb,
radius, station, source control, End, claim or mouth moves.

`OriginalJunctionBankDomain` verifies the real authored node incidences, native
Path objects, original profile/width/offset, exact `CurbCoordinates`, and a
positive contact on the opposite bank of that same original approach. A typed
generated `source_bank_fillet` cannot supply an original logical contact. Both
ends of an accepted contact must belong to the real node. The usable interval
ends before the fixed mouth, opposite contact and first original Section seam.
An explicit `OffsetCurb` native lead may connect the generated chain to that
bank; negative auxiliary extensions are generated fragments, not native body.

The unchanged original source-condition result is tried first. Only a failed
mixed-height generated chain may soften its generated cores/auxiliary leads.
Homogeneous closed corner chains and successful existing conditions remain
unchanged. The policy reconciles the whole resulting chain with the existing
`CurbEdge` quintic. For height difference `dz`, endpoint crossfall bound `k`,
length `L` and supplied physical limit `S`, it certifies

`sqrt((1.875 * abs(dz) / L)^2 + k^2) <= S`.

It chooses the first existing native knot satisfying that bound. The end on a
true inner bank reaches its exact peak with zero jet; the remaining bank and
full incoming profile stay unchanged. Missing maps, route seams, foreign
incidences, non-inner profiles, insufficient finite length or immutable
crossfall at the limit decline with `JunctionBankTransitionUnavailable`.
Arbitrary source errors are not caught as recovery candidates. Original STYLE
and STRICT radii/modes are never altered by this height-only rule.

The exact selected native intervals are carried in `TransitionBoundaryData`.
The builder retains that data for Product publication and consumers. Before
source-body reconciliation, `certify_body_domains` checks that no selected
interval overlaps a genuine hard body core. It never removes a source-body
constraint to accept a taper. The existing source/boundary, source-width and
mesh allocation limits still apply.

The Beijing 185 artifact demonstrated a 1.2845 m inner-bank prefix inside an
existing 9.5211 m original influence contact, leaving its 9.7711 m full profile
plane unchanged. A separate 691 condition experiment used the same native
contract through an explicit positive-station offset lead. These height
experiments do not qualify missing XY rounding, normal runtime Task integration
or untested source-body heights. Their generated reports remain in artifacts.

The maintained general policy subsequently reproduced both condition results.
An explicit `source_heights=True` Product on the exact saved 185 planar chart
also enforced the current source-body constraints: independent audit measured
zero error on all 14 hard body rows, complete supported body scope, stored
maximum slope 0.124991 below 0.130370, zero drainage fill, exact incoming
profiles/source-boundary heights and unchanged planar topology. This is a
supplied-chart artifact result. A normal chart rebuild, owned Task and cold
native qualification remain separate gates.

Native strip and port heights use the explicit `CurbCoordinates` ledger on
each retained span. A convenience polyline can include both banks and caps;
its curve index cannot identify an original bank. The ledger preserves the
actual native side, physical station, original Path and profile. Caps and
unowned or ambiguous source seams decline. A legacy curve without a ledger
is accepted only when its declared original bank is unambiguous; a non-unit
Exact miter requires the ledger.

Smooth bank jets use the analytical unit-normal transverse covector. Exact
jets use the derivative of the original line segment and its interpolated
miter normal, with one-sided native domains at control knots. Polynomial
prediction pieces are declared only at metric `Path.station(Path.knots)`
boundaries and real Route seams. These pieces do not add physical boundary
vertices or change incoming profile planes. Each prediction must retain the
ordinary degree-20 maximum and 1e-8 fit tolerance under the finite field budget.
