# Finite paired Bundle terminal profiles

A compound can own both original terminal junctions of an external Bundle.
Where its two original carriageways overlap, two independent complete incoming
profiles cannot both be exposed. The physical boundary instead has one merged
profile, while two `SourceMouth` records retain the original Section/end,
finite centreline station and half-profile parameter map.

The source-cycle planner discovers only complete, declared two-member Bundle
terminals whose two actual owners belong to the compound. A source Scope or
selection cut cannot supply a missing junction. Original local corners still
use their original approaches, dimensions and radius policies. Only the final
physical incoming ports are merged.

`FinitePairedEntrance` uses a transverse axial chart from the two actual
terminal tangents. It retains the complete Bundle run as inventory but limits
its local field to eight source widths of each crossing-adjacent Section, or
the original finite Section end. Smooth source derivatives have a bounded
Bernstein monotonicity certificate, regular offsets retain their source
certificate, and all four finite curb polylines must advance in the chart.
Exact paths retain every original curb bend. A profile cannot extrapolate a
curb or source centreline. The shared crown uses the existing dynamic Bundle
peak policy and its physical gradient; its outer joins remain at the datum.

Both original prefix strips are clipped at the same physical fibre and then
unioned. The construction inserts no node bridge or median fill. It requires
one overlapping finite union, an exact complete collinear profile, and internal
original root caps. Both source aliases intersect that fibre on their original
finite centrelines. The original full run remains available to the separate
Bundle body provider; that provider must consume this prepared entrance field
and its actual samples, because its own chart can use a different frame.

The final compound continuously contains both clipped source polygons, with
explicit exclusion of every known hole and interior boundary intrusion. Source
curb error plus boundary allowance is at most 2 mm. The same proof runs again
after boundary sampling. Consumed roads and ordinary prefixes retain their
separate complete-width proof. Mesh shape, stored-coordinate quality, profiles,
slopes, drainage, overlap and UV checks remain unchanged acceptance gates.

The original full-context Beijing compound at junctions 325/335/336/339 passes
the source planning proofs with two merged external terminals. Its normal
surface also passes after derived curb normalization: original profile samples
remain exact, projected union curbs differ by at most one micrometre, and the
unchanged complete source-width proofs run before and after normalization and
final boundary sampling. All dynamic layout metadata and original proof
operands survive the normalization.

The Bundle run can use a different, independently certified coordinate frame.
`MergedProfileBridge.build(..., target_inventory=...)` handles this finite
entrance branch. It requires continuous equality of all four original curb
chord chains over the connector and recertifies every complete original run
path in the target frame. Both outer leads remain on their original finite
curbs. One shared crest column transports the original front samples to a
complete target-field fibre. A quintic field blend has zero first and second
endpoint jets; the local field is never queried outside its certified range.
Derived support resampling stays inside the original source-curve allocation,
and continuous complete-quad containment excludes every original gap. Reports
record the source and additional polyline errors separately. The original
polar bridge branch keeps its existing arithmetic.

An explicitly prepared one-sided interior entrance uses the same transport
contract without pretending to be a complete Bundle run. Its two local visits
must be a subset of an explicit, role-ordered piece inventory. The bridge checks
the original Bundle membership, traversal orientation and consecutive original
incidences, then certifies the entire declared piece. The true near incidence
and the owner-scoped opposite cut keep their separate alias flags; the latter
is never resolved as an authored endpoint. Both supplied interfaces remain
byte-exact, including harmless round-off at their curb datum.

Both actual external terminal bridges pass stored-coordinate quality, physical
slopes, entrance bounds, drainage and UV checks. Complete segmented Bundle body
qualification remains separate; this document is not a whole-city completion
claim. Focused tests cover Exact/Smooth source geometry, reversed
storage, reflection, rotation and translation, source aliases, gradient values,
finite/domain rejection, changed run-frame/inner-curb rejection and a hole
wholly inside an original prefix.
